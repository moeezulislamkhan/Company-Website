# Innovexa Technologies — Frontend Website

This package is a **100% frontend-only** website. It contains static HTML, CSS and JavaScript only.

## Experience
1. Cinematic particle-assembly splash screen using the provided `assets/logo.jpg` as an off-screen particle target.
2. Main screen with exactly three animated hero banners.
3. Navigation: Home, Products, Industries, Services, Projects, Contact Us.
4. Video-ready showcase area with an included lightweight frontend demo video.
5. Static products, projects and customer reviews.
6. Frontend-only contact validation and simulated success state.
7. Responsive layouts and `prefers-reduced-motion` support.
8. Social media icons in the footer.

## Frontend-only guarantee
There is no backend, database, API, authentication, admin panel, CMS, server-side code, CRUD system, or server route in this package.

## CSS organization
Every HTML page has its own stylesheet:
- `css/index.css`
- `css/about.css`
- `css/products.css`
- `css/industries.css`
- `css/services.css`
- `css/projects.css`
- `css/reviews.css`
- `css/contact.css`

Social profile URLs in the footer are generic placeholders and can be replaced with the company's official profiles.
